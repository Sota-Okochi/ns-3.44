512以降は局所的横ばい傾向。学習量不足を排除はできないが、追加128件での平均改善は僅少。
576bestを保持し、追加収集だけを優先するより未使用共通seedで評価する。
1. 512/576/640とランダム・切り替えなしbaselineを未使用共通環境seedで比較。
2. 固定確率(例:40/33/27%)割り当てbaselineや端末特徴への感度を検証し、状態利用の価値を確認。
3. さらに同条件継続する場合は768を区切りとした追加実験とし、640latestから再開。
