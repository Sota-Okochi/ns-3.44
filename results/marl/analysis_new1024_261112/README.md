## 次の検証（推奨）
1. validationで選択済みの832bestを固定し、未使用ならtest1001〜1010でbaselineと比較。
   testの結果で再びモデル選択する場合は別の最終holdoutを用意。
2. 切替なし、一様ランダム、固定確率40/32/28%の状態非依存割当を同じ環境条件で比較。
   学習済み方策は確率的評価を維持し、argmaxに変更しない。
3. 端末特徴への出力感度とRTTタイムアウトの原因を調べ、必要なら別実験として状態・行動・報酬を改良。
単純延長の前に、状態を利用した意思決定の価値と汎化性能の確認を優先。
