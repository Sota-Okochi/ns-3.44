# 新条件・累計256エピソードの分析

実行: `python3 results/marl/analysis_new256_261025/analyze.py`
入力2runは同じexperiment_id。学習ID0〜255が重複・欠落なく存在。
学習256件と検証25件はすべてvalid=true。既存結果は変更していない。
このディレクトリのCSV/manifestは描画用の結合データで、再開用runではない。

固定検証5seedの平均H: 0=0.334643、64=0.337337、128=0.352089、
192=0.320294、256=0.314833。128比-10.58%、初期比-5.92%。
128→256で5seed中4seedが低下。差の参考95%対応ありt区間は
[-0.08537, 0.01086]。少数seedなので統計的な悪化/収束は断定しない。
256runのbest.ptは128時点、latest.ptは256時点を確認。

Critic EV(before/after)は256で0.75568/0.76597。Criticの説明力が
上がっても方策性能が改善するとは限らない。KL/損失の数値発散は見られず、
最新16更新のclip fractionは最大0.009863。0.1のclipが支配的な制約とする
証拠はない。entropyは128の1.08491から256の0.94245へ低下。
検証時平均AP0選択確率は42.47%→61.14%。偏りそのものは失敗としないが、
今回は固定検証Hの改善を伴っていない。因果関係は未確定。

判断: 無条件の追加128件を推奨するほど良好な推移ではない。
時間優先なら320を確認点とし、改善なしで512まで惰性で延長しない。
384まで実施するなら最終予算を決めた継続実験として扱い、128bestを保持。
詳細通信デバッグ・失敗率評価・追加シミュレーションは行っていない。

図のseed 1はモデルseed。validationは環境seed1011〜1015の平均。
学習曲線は環境seedが各episodeで異なり、16episode移動平均。
